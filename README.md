In my never ending quest to make my weather replacement Resource Pack better I decided I needed more control over when different weather sounds played, so I set out to add more tags for Resource Packs. One day this will hopefully have more than just weather sounds as well!

Use the tags the way you would any other Resource Pack tag from vanilla, for a full list of tags and what they do check the [wiki](https://github.com/vesmaybevesper/Extended-Sound-Tags/wiki) or a mod page ([Modrinth](https://modrinth.com/project/extended-sound-tags)/ [Curseforge](https://www.curseforge.com/minecraft/mc-mods/extended-sound-tags))

Please read the contributing document before opening a pull request.
